文法 · 40個 + 動詞變化 + 讀解 + 模擬試
1. 〜は〜です — A 係 B
わたし は がくせい です。→ 我係學生。
N5最基本，記住 は 讀 wa
2. 〜が あります / います — 有…（嘢 / 人）
つくえ の うえ に ほん が あります。→ 枱上面有書。
嘢用あります，人/動物用います
3. 〜を〜ます — 做…（賓語）
ほん を よみます。→ 睇書。
を 係將個動作指向邊樣嘢
4. 〜へ いきます — 去…
がっこう へ いきます。→ 去學校。
へ 讀 e，去邊度
5. 〜に いきます — 去做… / 幾時
デパート に かいもの に いきます。→ 去百貨公司買嘢。
に + 動詞原形 + にいく
6. 〜で〜ます — 用… / 喺…做
はし で ごはん を たべます。→ 用筷子食飯。
で = 用乜嘢 / 喺邊度做
7. 〜と〜ます — 同…一齊
ともだち と えいが を みます。→ 同朋友睇戲。
と = 同
8. 〜は〜より〜い — A 比 B 更…
にほん は ちゅうごく より ちいさい です。→ 日本比中國細。
比較句，より = 比
9. 〜のほうが〜い — 邊邊更…
でんしゃ の ほうが はやい です。→ 電車嗰邊快啲。
問邊個更…用呢個
10. 〜が すきです / きらいです — 鍾意 / 唔鍾意
わたし は ねこ が すきです。→ 我鍾意貓。
鍾意嘅嘢用 が，唔係 を
11. 〜が できます — 識… / 可以…
わたし は にほんご が できます。→ 我識日文。
能力句
12. 〜たいです — 想…
にほん へ いきたい です。→ 想去日本。
動詞ます形去掉ます + たい
13. 〜ないで ください — 唔好…
ここで たばこ を すわないで ください。→ 唔好喺呢度食煙。
禮貌叫人唔好做
14. 〜ても いいですか — 可唔可以…
トイレ に いっても いいですか。→ 可唔可以去廁所？
問准許，て形 + もいいですか
15. 〜ましょう / 〜ませんか — 一齊…啦 / 好唔好？
いっしょに たべましょう。→ 一齊食啦。
邀請人，ましょう係提議
16. 〜から〜まで — 由…到…
9じ から 5じ まで はたらきます。→ 由9點返工到5點。
時間 / 地方都得
17. 〜は〜に あります — 喺邊度
ほん は つくえ の うえ に あります。→ 書喺枱上面。
位置句
18. 〜んです — 解釋原因
あめ が ふっているんです。→ 因為落緊雨呀。
解釋點解咁，口語好常用
19. 〜て ください — 請…
まって ください。→ 請等一下。
て形 + ください，禮貌請求
20. 〜て います — 做緊… / 已經…
いま べんきょう しています。→ 而家溫緊書。
て形 + います，進行緊 / 持續狀態
21. 〜て もいいです — 可以…
ここで しゃしん を とっても いいです。→ 喺呢度影相都得。
准許
22. 〜て は いけません — 唔可以…
ここで たばこ を すっては いけません。→ 唔可以喺呢度食煙。
禁止，N5必考
23. 〜ないで ください — 唔好…
しずかに しないで ください。→ 唔好嘈。
唔好做，禮貌
24. 〜なければ なりません — 一定要…
あした までに しゅくだい を しなければ なりません。→ 聽日之前一定要做晒功課。
義務，唔做唔得
25. 〜なくても いいです — 唔做都得
きょう は こなくても いいです。→ 今日唔嚟都得。
唔使做都得
26. 〜た ことが あります — 曾經…
にほん へ いった ことが あります。→ 曾經去過日本。
經驗，た形 + ことがある
27. 〜た ほうが いいです — 最好…
はやく ねた ほうが いいです。→ 最好早啲瞓。
建議，最好咁做
28. 〜たり〜たり します — 有時…有時…
やすみのひ は テレビ を みたり、ほん を よんだり します。→ 放假有時睇電視，有時睇書。
列舉兩個以上動作
29. 〜から〜です — 因為…所以…
あめ が ふっているから、かさを もって いきます。→ 因為落雨，所以帶遮。
原因，から放喺原因後面
30. 〜ので〜ます — 因為…（禮貌）
びょうき なので、やすみます。→ 因為病咗，所以休息。
原因，比から更禮貌
31. 〜とき — …嗰陣
こどものとき、よく うみ で あそびました。→ 細個嗰陣成日去海邊玩。
嗰陣時，動詞原形/た形 + とき
32. 〜まえに〜ます — …之前
ねる まえに、はを みがきます。→ 瞓之前刷牙。
之前做乜
33. 〜あとで〜ます — …之後
ごはん を たべた あとで、さんぽします。→ 食完飯之後去散步。
之後，た形 + あとで
34. 〜と おもいます — 我諗…
あした は はれる と おもいます。→ 我諗聽日會晴。
諗法，普通形 + とおもう
35. 〜でしょう — 大概… / 係咪？
あした は あめ でしょう。→ 聽日大概會落雨。
推測，唔肯定
36. 〜かもしれません — 可能…
あした は あめ が ふる かもしれません。→ 聽日可能會落雨。
可能，比でしょう更唔肯定
37. 〜すぎます — 太…
たべすぎました。→ 食得太多喇。
太，動詞ます形去掉ます + すぎる
38. 〜やすくなります — 變得容易… / 變得…
にほんご が はなせる ように なりました。→ 變到識講日文喇。
變得能夠 / 變得…，ようになる
39. 〜ように します — 盡量… / 會…
まいにち にほんご を はなす ように しています。→ 我每日都盡量講日文。
習慣、努力
40. 〜が ほしいです — 想要…
あたらしい かばん が ほしいです。→ 想要個新袋。
想要嘢，用が

數量詞 · N5最易失分 · 齊晒 38個
N5出親嘅量詞全部入晒，仲有N4常用嘅泊、羽、皿。考試最鍾意考變音。
N5好鍾意考量詞讀音。重點唔係背晒，係背會變音嗰啲：1、3、6、8、10 最易錯。
1. 〜つ — hitotsu...
【萬能量詞】數細件、唔知用咩量詞就用佢
例：りんご 1つ → 1個蘋果
1つ ひとつ、2つ ふたつ、3つ みっつ、4つ よっつ、5つ いつつ、6つ むっつ、7つ ななつ、8つ やっつ、9つ ここのつ、10つ とお，N5一定要背晒

例：たまご 3個 → 3隻蛋

數薄嘅嘢：紙、衫、相、CD、郵票
例：シャツ 2枚 → 2件衫 / 紙 3枚
1枚 いちまい、2枚 にまい，讀音唔變，最易
4. 〜本（ほん） — hon
數長嘅嘢：筆、樽、傘、樹、電車
